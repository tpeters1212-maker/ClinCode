# Pediatric foot and ankle abstraction

## How to work a note
1. Read the **Focus** panel. Highlighted words show where to look; they are not answers.
2. Tick every topic the note documents in **What does this note document?**
3. Answer questions only for the topics you ticked. Unticked topics are recorded as *Not documented* automatically.
4. Select supporting sentences in the full note with the **Evidence** labels.
5. **Submit**, or **Save draft** to finish later.

*Not documented*: the note does not say. *Unclear*: the note says something but you cannot tell what. A normal finding is an answer (for example Neutral or Absent), never Not documented.
