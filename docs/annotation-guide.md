# Pediatric foot and ankle abstraction

## How to work a note
1. Read the Focus panel. Highlighted words show where to look; they are not answers.
2. Tick every topic the note documents. Questions for that topic appear.
3. Answer every question in the topics you ticked. Unticked topics are recorded as Not documented automatically.
4. Select the supporting text in the note and click the topic it supports to save it as evidence.
5. Answers save automatically. Click Submit when the note is finished.

- Not documented: the note does not say.
- Unclear: the note says something, but you cannot tell what.
- A normal finding is an answer (for example Neutral or Absent), never Not documented.
- Answer from this note only. Do not open other notes for the same patient.
- Numbers: type the value. Leave blank if not documented. Type ? if unclear.
