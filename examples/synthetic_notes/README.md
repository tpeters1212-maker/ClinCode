# Synthetic notes

Ten fabricated pediatric foot and ankle notes for tests, demos, and training.
Every name, date and finding is invented. Never add real clinical text to this repository.

Cases covered: nighttime versus unspecified AFO timing, "lacks N to neutral" (negative DF),
side-specific values, casting, surgery, a normal flatfoot exam, a non-clinical telephone
note, a partially examined patient, and longitudinal notes for one patient (P01).
